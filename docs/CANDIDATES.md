# 頭の動かし方の経緯

| 方式 | 結果 |
| --- | --- |
| 頂点ごとの2.5D変形・ボーン・分離型の視差・生成絵へのキーフォーム | 一枚絵を曲げたような歪み |
| 部位ごとに剛体でずらす（v5〜v10） | 歪みは出ないが、顔がお面のように髪の中を滑って見える |
| **頭全体を1枚の板として傾ける・うなずく（r1、現行）** | 横向きをやめ、絵のどこも曲げない |

r1 の判定（`scripts/rigid_check.py`）：静止 12 姿勢すべて合格、確認用モーション 200 コマすべて合格
（頭の全部位のずれ 0.5px 以下、各部位の曲がり 0.5px 以下、揺れる髪の折れなし、すき間なし）。
加えて、全区間の要所を実寸で目視確認。

あわせて直した不具合：驚き顔の口の絵が縦に 55% までつぶれて表示されていた（口の開閉の変形がかかっていた）。

## r1 の改良（2026-09-30）

- 瞬き・口パクを「絵の切り替え」に変更（目の絵をつぶす、口の絵を伸ばす変形をやめた）。半開きの口を生成して追加。
- 表情の切り替えで、前後の絵が半透明で重なる二重像が出ていたのを修正（絵の切り替えは必ず一段で、表情の重みは常に合計1）。
  1/60 秒刻みで全 1200 コマを調べ、半透明のコマが 0 であることを確認。
- 瞳が白目からはみ出していたので可動域を狭めた。
- 首かしげ・うなずき・体の傾きに、ばねによる追従・行き過ぎ・戻りを付けた。話しながらの小さなうなずき、体の傾きに頭が少し遅れる動き。

## r3（現行）：髪を束に沿って曲げる

r1 は後ろ髪で「上は頭・下は体」と頂点の位置を混ぜていたため、首を傾けると後ろ髪がせん断されていた。
自作の判定も揺れる髪を別扱いにしていたので、見逃していた（線形ブレンドスキニングのせん断。docs/RESEARCH.md の資料 11）。

r3 では、判定を「全部位・全三角形で回転以外の変形 5% 以下、例外なし（手前の部品に完全に隠れた三角形のみ除外）」に作り直した。
そのうえで次のように直した。
- 後ろ髪・横髪・リボンの紐：芯に沿った回転の連なりで曲げる
- 物理：位置ではなく曲がる角度だけを揺らす
- スカート：位置をずらす揺れをやめた
- 瞳：寄り目のときの横縮みをやめた

結果：静止 10/10、確認用モーション 600/600、首振りモーション 360/360、頭の一体性 12/12 と 200/200。いずれも合格で、最大の歪みは 4.4%。

リボンの垂れ（幅が広い）は、揺らすと曲がりが大きくなるので揺らさない（頭の傾きに応じて垂れるだけ）。
確認用モーションの揺れ区間は、±30° を 0.35 秒で往復する人間離れした速さだったので、±22° を 0.6 秒の自然な速さに変えた。
